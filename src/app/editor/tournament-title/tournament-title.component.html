Write below the title of your tournament. That is the text that will appear on the window tag (e.g. "BGA Entry form generator" for this page). This is also used as a placeholder for the title above the entry form. You can also select the width of the BGA logo. You can further edit or remove both these values in the next step.

If left blank the title will default to "{{tour_config.getEmptyTourTitle()}}" which is obtained based on the previously provided tournament name (i.e. "{{tour_config.getTourName()}}").
